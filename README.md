# E-commerce Sales Analysis

An exploratory data analysis project focused on understanding e-commerce sales performance, identifying trends, and generating actionable business insights using Python.

## Project Overview

This project analyzes e-commerce sales data to explore revenue performance across product categories, cities, and months. It demonstrates how data analysis can help identify business patterns and support data-driven decisions.

## Objectives

- Analyze revenue across product categories and cities.
- Examine monthly revenue trends.
- Identify high-performing and low-performing categories.
- Summarize findings and suggest business recommendations.

## Tools and Technologies

- **Python**
- **NumPy**
- **Pandas**
- **Matplotlib**
- **Jupyter Notebook**

## Key Findings

- **Top product category:** Electronics generated the highest revenue among the analyzed categories.
- **Top-performing city:** Kolkata recorded the highest revenue in the analysis.
- **Best month by revenue:** August recorded the highest monthly revenue, approximately ₹94,121.76.
- **Lowest month by revenue:** October recorded the lowest monthly revenue, approximately ₹26,986.55.

These findings describe the dataset analyzed and should not be treated as proof of the causes behind sales performance.

## Project Files

- `Ecommerce_Sales_Analysis.ipynb` — notebook containing the analysis, visualizations, findings, and recommendations.
- `ecommerce_sales_data.csv` — dataset used in the analysis.

## How to Run

1. Download or clone this repository.
2. Install Python and the required libraries:

   ```bash
   pip install pandas numpy matplotlib jupyter
   ```

3. Open `Ecommerce_Sales_Analysis.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells from top to bottom.

Keep the CSV file in the same directory as the notebook so it can be loaded correctly.

## Business Recommendations

- Investigate why Electronics generates more revenue than other categories.
- Compare order counts and revenue per order across categories.
- Monitor monthly sales trends to identify periods that may need further investigation.
- Use additional data, such as discounts, costs, and customer behavior, to better understand sales performance.
